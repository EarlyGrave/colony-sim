## Design decisions (log in DECISIONS.md "decided without owner, review")
- **Facade, not rewrite**: `TraitSystem` (v2, `sim/colonists/trait_system.gd`) keeps its helper names; with `traits_v3_enabled` it forwards to `TraitSystemV3` and ADDS `sim.passives.mod(c, stat)` inside `mod()`. Consumers already calling `sim.traits.*` need no edit; passives reach them for free (additive on the existing `1.0 + ...`).
- Overlap files (combat_system, job_system, mood_system, health_system, building_system...) are edited by W1 and W3 in separate `# region F11W1` / `# region F11W3` blocks, one line per hook.
- Only the highest-value NEW traits-v3 stats are hooked this wave (max_hp, melee_damage, heal/severity, rest_*, alarm_delay, target_weight, mining/research/scrub speed, leaning_*, aura_*); the rest of the integration.md table is a follow-up batch (note in W1 report).
- Save: trait ids already live in `c.bio`; passive state serialised per inmate via `PassiveSystem.state_parts()`; both in `state_hash` only when the flag is on.
