# Передаточный файл для автора следующего промпта (после сессии 3, 2026-10-17)

Этот файл самодостаточен: по нему можно написать промпт на следующую сессию,
не открывая код. Остальные документы — для агентов внутри сессии.

## 1. Состояние проекта в одном абзаце
Godot 4.7.2, GDScript, web-сборка. Играбельный срез Э0–Э8 влит в `main` и
опубликован на https://earlygrave.github.io/colony-sim/ . В ветке
`claude/colony-sim-godot-4jftsm` (в `main` НЕ влита) лежат Э9–Э11 сессии 2
(рассказчик, правило инженера, баланс, пиксельная графика) и вся сессия 3.
Тестов 57, все зелёные, CI гоняет тесты и web-экспорт на каждый пуш.

## 2. Что сделала сессия 3 (промпт «каркас систем Э9–Э22»)
Выполнен только **Э9**, целиком документами, код игры не менялся:
- `docs/ARCHITECTURE.md` — аудит текущего кода, 23 сигнала шины, команды игрока, точки расширения.
- `docs/contracts/` — 7 контрактов: `items-inventory`, `recipes-buildings`,
  `colonists-needs-jobs`, `combat-weapons`, `research-events-save`, `ui-touch`,
  плюс `README.md` (индекс и сверка) и `RECONCILIATION.md` (10 расхождений,
  **все решены, обязательны для Э10+**, см. D25).
- `art/STYLE.md` — стайлгайд из существующего генератора `tools/gen_art.py`, цвета 9 новых ресурсов.
- `docs/economy/resources-and-chains.md` — 39 предметов, 24 рецепта, стоимости 24 построек, граф, свёртка сырья.
- `docs/economy/items.proposed.json` — готовый `data/items.json` на 36 предметов для Э10.
- `tests/test_long_sim.gd` — 10 000 тиков, закон сохранения предметов + детерминизм.
- `docs/agents/*/E9-report*.md` — отчёты агентов; `docs/agents/qa/E10-test-plan.md` — черновик плана тестов Э10.
- `DECISIONS.md` D20–D25, `PROGRESS.md`, два handoff-файла.

Этапы **Э10–Э22 не начаты**. Для каждого есть контракт (таблица в
`docs/handoff/session-2026-10-17-summary-by-stage.md`).

## 3. Решения, которые уже приняты (не поднимать заново)
- D21/D25: id предметов `refined_essence`, `waste` остаются; промптовые
  `essence_refined`/`toxic_waste` НЕ используются. Новые id — как в промпте.
- D23: турели тратят `ammo_basic`, оружие колонистов патроны не тратит.
- D25: `recipes` (массив) у постройки; 9 навыков (mining, construction,
  crafting, smelting, shooting, melee, medicine, cooking, plants), навык
  рецепта может быть `null`; приоритет склада `storage_priority` 0..3
  (low/normal/high/critical), приоритет работ — отдельный `work_priority`;
  одна команда `equip_item`; оружие/броня — предметы, боевые числа в
  `weapons.json`/`armor.json` под тем же id; `order_attack(colonist_id,
  enemy_id)`; бой только ранит, смерть решает модель здоровья; закрытый enum
  причин в `Ledger`; сохранение покрывает всё состояние с round-trip тестами;
  аргументы сигнала `story_event` заморожены.
- D18: стресс и срывы отложены владельцем. D20: контракты до кода.
- Из CLAUDE.md: сим отделён от вида, фиксированный тик, весь рандом через
  `sim.rng`, данные в JSON, команды игрока только через `Simulation`.

## 5. Важное ограничение: бюджет
Сессия 3 длилась 13 минут и стоила ≈ $23 подарочных кредитов (15 субагентов
на Sonnet/Haiku + оркестратор с большим контекстом). Остаток ≈ $225. Владелец
хочет, чтобы следующие сессии списывались с подписки, а не с кредитов —
проверить перед запуском. В промпт стоит заложить экономию:
- одна волна агентов на этап, не три; агентов 3–5, не 12;
- субагенты на Sonnet, оркестратор не перечитывает файлы, которые читали агенты;
- отчёты агентов короткие (до 40 строк), без дублирования контрактов.

## 6. Что должен содержать следующий промпт
1. Старт: прочитать `CLAUDE.md`, `PROGRESS.md`, `DECISIONS.md` (D20–D25),
   `docs/contracts/README.md` и `RECONCILIATION.md`. Не переписывать контракты
   с нуля — только внести решения 1–10 в тексты контрактов (один агент, ~10 минут).
2. **Э10** (предметы, стаки, инвентарь, склады с фильтрами и приоритетами):
   взять `docs/economy/items.proposed.json` → `data/items.json`; реализовать по
   `docs/contracts/items-inventory.md`; тесты по `docs/agents/qa/E10-test-plan.md`;
   критерий — закон сохранения на 10 000 тиков (тест уже есть, расширить на новые предметы).
3. **Э11** (деревья, скалы, месторождения, генерация по сиду), затем Э12–Э13.
   Э14+ только если останется бюджет.
4. Правила автономной работы те же: пуш после каждого этапа, никогда с
   падающими тестами, PROGRESS/DECISIONS по ходу, handoff в
   `docs/handoff/session-<дата>-handoff.md` в конце.
5. Явно указать лимит времени или денег на сессию и правило «за N минут до
   конца — только довести до зелёного, закоммитить, написать handoff».

## 7. Известные долги, которые промпт может поручить попутно
- Нет теста save→load (система сохранения ещё не написана) и юнит-теста `Ledger`.
- Русские строки в коде не переведены на `tr()`-ключи (контракт `ui-touch.md` задаёт схему).
- Материалы оружия в `combat-weapons.md` (`scrap`, `iron`…) не сверены с id предметов.
- Цвета новых ресурсов из `art/STYLE.md` не проверены на экране телефона.
- Баги из PROGRESS.md: колонисты игнорируют врагов без тревоги; прогноз скачет после
  разрушения установки; твари проходят сквозь друг друга.
