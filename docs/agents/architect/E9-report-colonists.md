## Принятые решения
| Тема | Решение |
|---|---|
| Потребности | `hunger`, `rest` затухают линейно (`decay_per_tick`); `health` производная от `hp/max_hp`. Пороги с эффектами `work_speed_mult`, `faint`, `death`, `critical` |
| Настроение | Только скаляр `Colonist.mood`, без срывов и без влияния на геймплей; позже подключается модуль `sim/mood/` после колонистов в порядке тиков |
| Ранения | `Colonist.injuries` (`bleeding`, `bruise`), лечение работой `tend` с `bandage`/`herbal_medicine`, единственный вход `ColonistSystem.injure()` |
| Смерть | Через существующий `ColonistSystem.kill()` (hp <= 0 или порог `death`) |
| Сон и еда | Здание `bed`, опциональная зона сна; `nutrition` в `items.json`; работы `eat`, `sleep`, `tend`, `sow`, `harvest`, `cook` |
| Навыки | `Colonist.skills`, 9 навыков, кривая опыта, `speed_mult_per_level`, шанс успеха через `sim.rng` |
| Приоритеты | `ColonistSystem.work_priority` (0 = никогда, 1 высший ... 4 низший), команда `Simulation.set_work_priority(id, job, prio)` |
| Порядок решений в `JobSystem` | flee на тревоге > обморок/болезнь > критические потребности (игнорируют таблицу) > доставка груза > работы по приоритету 1..4, внутри группы число из `jobs.json`, затем расстояние |
| Инвентарь | Только ссылка на `docs/contracts/items-inventory.md` |
