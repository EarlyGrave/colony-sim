# Отчёт architect E9: бой, оружие, турели с боеприпасами (этап E17)

## Что сделано
- Написан контракт `docs/contracts/combat-weapons.md`: схема `data/weapons.json` (7 видов оружия), броня (3 вида), формула попадания и урона, призыв колонистов (draft), турели с патронами, 3 новых типа врагов, новые сигналы шины, критерии тестов, открытые вопросы.
- Код и существующие документы не менялись.

## Принятые решения
| Решение | Выбор |
|---|---|
| Волны, сила, таймер, отступление | без изменений |
| Формула попадания | accuracy * навык * дистанция * (1 - укрытие), зажим 0.05..0.95, бросок только через `sim.rng` |
| Броня | доля `damage_reduction`, минимум 1 урона |
| Здоровье колонистов | через `sim.colonists.injure(c, type, severity)` из контракта колонистов; без состояния "без сознания" в E17 |
| Draft | `draft`, `order_move`, `order_attack(colonist_id, enemy_id)` в `Simulation`; призванные игнорируют работы и тревогу |
| Патроны у колонистов | не тратятся (записанное решение) |
| Турели | `ammo_item/ammo_capacity/ammo_per_shot`; новая турель пустая; `ammo_basic`, `heavy_turret` |
| Перезарядка | `ReloadTurretJob` (подвоз) или конвейер/манипулятор |
| Враги | поля `armor`, `attack_damage`, `prefers_buildings`, `spawn_weight`; типы skitter, carapace, gnawer |
| Состав волны | взвешенный выбор по `spawn_weight`, id в отсортированном порядке |
| Сигналы | `colonist_drafted`, `turret_out_of_ammo`, `shot_fired`, `enemy_damaged` |

## Заглушки и долги
- Все числа оружия, брони, врагов и турелей стартовые; нужен прогон `tools/balance_report.gd`.
- Названия материалов (`scrap`, `iron`, `steel`, `cloth`) условные, нужно свериться с `data/items.json`.
- Время ограничено (6 минут): `ThreatSystem._tick_turrets` и `damage_enemy` читались только по списку функций, детали интеграции уточнит исполнитель.
