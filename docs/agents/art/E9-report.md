## Принятые решения
| Тема | Решение |
|---|---|
| Тайл | 16 px исходник, 32 px на экране (2x), фильтр nearest |
| Обводка | 1 px `#1a1420` у всех объектов, у тайлов земли нет |
| Свет | сверху-слева, 2–3 тона на материал, без дизеринга |
| Зарезервированные оттенки | фиолетовый = эссенция, ядовито-зелёный = отходы, красный = враги, оранжевый = колонисты |
| Новые ресурсы | свой оттенок и свой силуэт; железо и медь различаются и цветом, и узором |
| Анимация | 2–4 кадра для машин/ходьбы/атаки, размер и палитра как у кадра 0; всё косметическое |
| Имена файлов | `<kind>_<id>[_<frame>].png`, старые имена пока остаются |
| Пайплайн | только генерация из `gen_art.py`, PNG руками не правим; коммитим PNG + `.import` |
