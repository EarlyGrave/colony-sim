## Принятые решения

| Решение | Значение | Почему |
|---|---|---|
| Id эссенции | оставить `essence_ore`, `refined_essence`, `waste` | не ломать текущие данные и тесты |
| Топливо | тег `fuel` у `coal` и `charcoal`; рецепты принимают любой предмет с тегом | угольная цепочка не блокируется, дерево становится запасным топливом (3 дерева = 1 уголь) |
| Новые поля предмета | `tier`, `category`, `weight`, `tags` | в текущем `items.json` только name/color/stack/contaminates |
| Новые поля рецепта | `building`, `skill` | сейчас рецепт привязан только к имени |
| Навыки (предложение) | crafting, smithing, engineering, cooking, medicine, construction | системы навыков в данных нет, нужно сверить |
| Стоимость зданий | sawmill/smelter/assembly по заданию, остальное - стартовые значения | помечено как точки старта для балансировки |
| Итог свёртки | engine = 28 железной руды + 16 угля; machine_frame = 16 + 10; simple_circuit = 2 Fe + 1.33 Cu + 2.67 угля + 2 песка; 10 патронов = 2 Fe + 2 Cu + 3 угля | уголь - главное узкое место |
