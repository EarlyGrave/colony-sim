## C1 squads "Wardens of the Line"
Owns `sim/squads/squad_system.gd`, `sim/squads/squad.gd`, `data/roles.json`, `data/traits.json` (region C1: `role_affinity`), `sim/core/simulation.gd` (region C1), `data/rules.json` (none), `docs/sim_contract.md` rows, `tests/test_squads.gd`.
- Squad: id, name, `members:Array[int]` (max `roles.max_size` = 4), `role_of:{id:role}`, `hold:Vector2i` (or -1), `focus:int` (enemy id or -1). Roles `bulwark`, `lancer`, `medic` in `data/roles.json` {name, weapon, dmg_taken_mult, threat_mult, formation_offset, affinity_traits/skills, ability id}. Role pick: auto-suggest by affinity (trait `role_affinity` from the inmate record + skill melee/shooting/medicine), player can override.
- Commands on Simulation (logged, replay-equal): `form_squad(ids, roles)`, `disband_squad(sid)`, `squad_hold(sid, cell)` (members drafted + `order_move` to anchor+offset, Bulwark front / Lancer behind / Medic rear), `squad_focus(sid, enemy_id)` (members `order_attack`; Medic ignores). Disband un-drafts.
- Auto-behaviour with no focus: nearest enemy in weapon range of the anchor; Bulwark holds the anchor; no per-inmate orders.
- Accept: form with 4 -> 4 drafted, 5th rejected; hold puts all within 2 cells of their offsets within 60 ticks on an open map; focus makes all non-medics target that id within 2 ticks; disband clears drafted; affinity test (3 fixture inmates -> expected roles); dead member leaves the squad; same commands twice = equal `state_hash`; goldens unchanged; plain `set_drafted` path test still green.

## C2 role abilities (taunt / volley / stabilise)
Owns `sim/squads/abilities.gd`, `data/roles.json` (region C2: `abilities` block only), `data/weapons.json` (region C2: `abilities`), `sim/threats/threat_model.gd` (region C2: `colonist_value` reads `c.threat_flags`), `sim/colonists/colonist.gd` (region C2: `threat_flags:Dictionary`), `sim/contamination/contamination_system.gd` (region C2: `add_puff(cell, amount)` if no equivalent exists), `tests/test_abilities.gd`.
- Command `use_ability(sid, ability_id)`; data per ability: `cooldown_ticks`, `essence_cost`, `contam_puff`, `noise_burst {mult, ticks}`, plus: Bulwark taunt `{mult:4, ticks:150, radius:6}` (sets `threat_flags.taunt` -> threat x mult; ThreatModel stick 0.7 still applies); Lancer volley (next shot burst x2 damage for 3 shots); Medic stabilise (stops bleed-out timer of Down inmates within range, see C4).
- Each use takes essence from storage (shortfall -> rejected, no debt), drops the contamination puff at the user's cell, and sets threat flag `burst` (x3) for `noise_burst.ticks`, so the squad can act as a mobile decoy.
- Accept: taunt: 10 crawlers, Bulwark vs a plain inmate at equal distance -> >= 80% of picks hit the Bulwark during the window and < 50% after it; cooldown rejects reuse for `cooldown_ticks` (+-0); essence stock drops by exactly `essence_cost`; contamination at the cell rises by `contam_puff` (+-1%); volley deals >= 1.9x damage on the first shot; flags clear on expiry; no effect without a squad; goldens unchanged.

## C3 telegraphed creature attacks
Owns `sim/threats/enemy.gd` (region C3), `sim/threats/threat_system.gd` (region C3: wind-up state machine), `data/enemies.json` (`telegraph` per species), `view/telegraph_layer.gd`, `view/world_view.gd` (region C3: add layer only), `tests/test_telegraph.gd`, `tests/test_telegraph_view.gd`.
- `telegraph: {windup_ticks, shape:"cell"|"line"|"area", radius|length, dmg_mult}`. Brute slam = area r1 (windup 20), Spitter = line length 6 (windup 14), Burrower = cell erupts (windup 24), Crawler none. Sim: when an enemy would attack with a telegraph, it first locks `telegraph_cells` + `windup_left`; at 0 all entities still in those cells take `damage*dmg_mult`; anything that left is untouched (dodge by position, no accuracy roll for enemies; inmate hit chance unchanged). Deterministic, no rng.
- View draws red marked cells + a shrinking ring (radius ~ windup_left/windup_ticks); first-ever telegraph shows a one-time hint (no auto-pause).
- Accept: windup lasts exactly `windup_ticks` (+-0); inmate moving out of the marked cells takes 0 damage, staying takes `damage*dmg_mult`; area hits >= 2 targets once each; enemy killed during windup cancels the strike; state_hash includes telegraph state only while active; view test: cells = `telegraph_cells`, ring scale monotonic decreasing; goldens re-run: waves without telegraph data unchanged; document intentional golden shift if species data enables it (regenerate with `make_golden.gd`, list in report).

## C4 3-state injuries over the existing health model
Owns `sim/health/health_system.gd` (region C4), `sim/health/health_state.gd` (region C4), `data/health.json` (`states`), `sim/jobs/rescue_job.gd` (new), `sim/jobs/job_system.gd` (region C4: work-giver), `tests/test_injury_states.gd`.
- Do NOT delete parts/injuries/bleed/infection. Add derived `HealthSystem.band(c) -> "fit"|"wounded"|"down"`: Wounded when total_damage/max >= `states.wounded_below` (0.4 damage fraction) or manipulation/moving < 0.7 (then -dmg/-speed via existing multipliers); Down = existing `is_downed`. Down starts `bleedout_ticks` (900 default, data) timer, ticks only if bleeding; reaching 0 = death; `tend()`/Medic stabilise/bed stops it.
- Auto-rescue: any idle undrafted inmate with a free reservation carries a Down inmate to a bed (`rescue:<id>` key); no micro. Without a bed, to the nearest safe cell.
- Accept: band thresholds on 6 fixtures; Down inmate with no help dies at bleedout +-1 tick; with an idle inmate within 12 cells is in bed within 300 ticks in 5 seeds; stabilise (C2 stub: `health.stabilise(c)`) freezes the timer; old save-free: states are derived, no save field except timer; goldens unchanged unless a golden fight downs someone (then regenerate and list).

## C5 touch UI, forecast panel, militia, QA
Owns `view/panels/squad_bar.gd`, `view/panels/forecast_panel.gd`, `view/ability_radial.gd` (reuses `radial_menu.gd` API, no edits there), `view/game.gd` (region C5: `_squad_tap` before `_combat_tap`), `view/hud.gd` (region C5), `sim/squads/militia.gd` + `data/roles.json` (region C5: `militia`), `tests/test_squad_ui.gd`, `tests/test_militia.gd`, `tests/qa_combat_bot.gd`, `tools/combat_report.gd`.
- Bottom bar: banners (>= 64 px) per squad + "Form squad". Tap banner -> select; tap ground = `squad_hold`; tap enemy = `squad_focus`; long-press banner (>= 0.45 s) = ability radial (taunt/volley/stabilise, each >= 64 px, ready/cooldown shown). Ignore `DEVICE_ID_EMULATION` mouse events. Time slows to 0.3x while the radial is open.
- Forecast panel before a wave: composition, approach side, ETA from `wave_incoming` + ForecastModel/ecology; panel button >= 64 px; no new sim state.
- Militia: on `set_alarm(true)` unassigned, undrafted, healthy inmates run to the nearest banner and fight with `shiv`, no role, flee at `flee_hp_fraction`; released on alarm off.
- QA: `qa_combat_bot` uses only public commands. Table `tools/combat_report.gd`: 25 game days x seeds 1..5, "with squad" (1 squad of 3 roles, hold + focus + abilities) vs "no squad" (current behaviour): wave_repelled count, colonists_dead, inmates Down-seconds, contamination at day 25, essence spent.
- Accept: synthetic touch tests (banner tap selects, ground tap emits exactly 1 `squad_hold`, enemy tap exactly 1 `squad_focus`, long-press opens 3 slots >= 64 px, emulated events ignored); militia: 3 idle inmates reach banner <= 10 cells in <= 120 ticks, none after alarm off; HUD rect scan at 844x390: no overlap with tutorial card/thumb cluster, map area >= 60% height; QA: squads reduce colonists_dead summed over seeds by >= 30% vs no-squad (report actual, do not tune to pass), 0 script errors, deterministic per seed.
