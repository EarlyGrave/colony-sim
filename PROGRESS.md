## Отчёт владельцу (сессия 1)
**Готово:** Э0–Э8. 45 headless-тестов, CI зелёный на каждом пуше.

**Сборка:** https://earlygrave.github.io/colony-sim/ — появится после слияния
ветки `claude/colony-sim-godot-4jftsm` в `main` (деплой идёт только с `main`).
Что потрогать с телефона (лучше горизонтально):
1. Пан пальцем, пинч-зум. «Добыча» → два тапа по углам области с фиолетовой рудой.
2. «Свалка» → два тапа; «Установка» → тап по свободному месту (2×2, 20 руды).
3. Скорость 3x. После первой партии появится прогноз конца планеты.
4. Когда будет эссенция — «Турель». Дождись волн: без турелей колония
   погибает на 2-й волне. «Тревога» вручную — спрятать людей / выпустить чинить.
5. `?seed=42` в адресе — одна и та же карта.

**Решения, принятые самостоятельно** (подробно в DECISIONS.md): Godot вместо
TS-движка из диздока; свой тест-раннер вместо GUT; данные в JSON; задачи по
модели «work giver» с резервированием; склад-цель врагов = капсула (у зон нет
HP); волны заканчиваются по таймеру и твари отступают; ремонт пока бесплатный;
масштаб UI по devicePixelRatio.
